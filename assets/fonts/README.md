Source: https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/Variable/TTF/Subset/NotoSansTC-VF.ttf
License: OFL.txt in this directory.

The bundled static TrueType instance was generated with fontTools varLib.instancer at wght=400.
Command: `fonttools varLib.instancer NotoSansTC-VF.ttf wght=400 --output NotoSansTC-Regular.ttf`
PDFs embed only the glyphs used. No external font requests are made at runtime.
